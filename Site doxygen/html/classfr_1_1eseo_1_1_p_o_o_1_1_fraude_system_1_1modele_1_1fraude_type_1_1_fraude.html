Detailed Description

Classe abstraite représentant une fraude.

Cette classe sert de base (classe mère) pour tous les types de fraudes :

  • Iag
  • IagConnecte
  • Papier
  • Calculatrice

Elle contient les informations communes à toutes les fraudes :

  • la date du relevé
  • une description
  • un contenu frauduleux

Comme elle est abstraite, on ne peut PAS créer directement un objet Fraude. On doit obligatoirement créer un objet d’une classe fille.
