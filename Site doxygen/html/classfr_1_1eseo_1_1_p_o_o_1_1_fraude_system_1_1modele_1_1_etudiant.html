Detailed Description

Classe représentant un étudiant dans le système de fraude. Chaque étudiant possède :

  • un identifiant unique généré automatiquement
  • un nom
  • un prénom
  • un cursus (Enum : B1, B2, B3, E1, E2, E3e, etc.)
